# UIDAI Credential Wallet PWA

## Features
- Responsive Credential Dashboard
- Secure Sensitive Data Reveal
- Auto Remasking after 10 seconds
- Accessibility Support
- Offline PWA Support
- Automated Testing with Jest

## Tech Stack
- React
- TypeScript
- Context API
- Jest
- React Testing Library

## Run Project

```bash
npm install
npm start
```

## Run Tests

```bash
npm test
```
